# Paper framework figures

These figures are rendered from the original framework illustrations in the author-provided accepted-paper sources. Their scientific content has not been edited.

| Asset | Original source | Publication |
| --- | --- | --- |
| `bpta-framework.png` | `bpta.pdf` in the BPTA source archive | Zhiyuan Li, Wenshuai Zhao, Lijun Wu, and Joni Pajarinen. [Backpropagation Through Agents](https://doi.org/10.1609/aaai.v38i12.29277). AAAI 2024. |
| `agentmixer-framework.png` | `figs/agentmixer.pdf` in the AgentMixer source archive | Zhiyuan Li, Wenshuai Zhao, Lijun Wu, and Joni Pajarinen. [AgentMixer: Multi-Agent Correlated Policy Factorization](https://doi.org/10.1609/aaai.v39i17.34048). AAAI 2025. |

Both complete framework pages were rendered to 2,000-pixel-wide PNGs with PyMuPDF 1.26.5. The original PDF source hashes and rendered asset hashes are recorded in `paper_figures.json`.
